# Jessie Lin — Portfolio

以 Vue 3、Vite、TypeScript、Pinia、SCSS、GSAP、Lenis 與 Iconify 製作的日系極簡個人作品集範本。

## 開始使用

```bash
npm install
npm run dev
```

## 自訂內容

- 在 `src/data/portfolio.ts` 集中調整導覽、技能、作品與經歷資料。
- 在 `src/assets/styles/_tokens.scss` 調整色彩、字體與版面間距 token。
- 將 `src/components/HeroSection.vue` 裡的個人形象照換成自己的圖片；作品封面可在 `src/data/portfolio.ts` 置換。
- Demo 與 GitHub 連結目前為範例網址，正式上線前請替換。
